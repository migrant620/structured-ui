Third-party notices for Structured UI Prototype

This file covers the fonts and images bundled with the build, plus the
JavaScript dependencies. Notices for the JavaScript dependencies are
enumerated below and expanded in the publication step.

------------------------------------------------------------

  Source: The Roboto Project (googlefonts/roboto-classic), downloaded for
  this project.
  Licence: SIL Open Font License 1.1.
  Use: all interface copy. The build ships twelve static instances cut from

JAVASCRIPT DEPENDENCIES
------------------------------------------------------------

The build depends on Expo, React, React Native, react-native-web,
react-native-svg, react-native-safe-area-context, expo-font, expo-status-bar
and expo-system-ui. Each is distributed under its own licence (predominantly
MIT). The exact versions are pinned in package.json and expanded in the
publication step.
